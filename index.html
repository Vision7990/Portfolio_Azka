MIN INRIKTNING

Det jag vill utvecklas inom

Mitt intresse ligger framför allt inom områden där teknik, programmering och säkerhet möts. Jag vill förstå både hur webbplatser och program byggs och hur de kan göras säkrare och mer användarvänliga.

Webbutveckling

Jag arbetar med HTML och CSS och lär mig att bygga webbplatser med tydlig struktur, semantiska element, responsiv design och tillgänglighet.

Programmering

Jag tränar på programmeringslogik, variabler, villkor, problemlösning och att dela upp problem i mindre delar som går att lösa med kod.

Cybersäkerhet

Jag är intresserad av hur information, användare och digitala system kan skyddas mot vanliga säkerhetsproblem och hur säkerhet kan byggas in redan när en lösning utvecklas.

Min inställning till lärande

Jag tror att man lär sig mest genom att faktiskt prova. När något inte fungerar försöker jag hitta orsaken, testa en lösning och sedan kontrollera resultatet.

Därför använder jag även verktyg som DevTools när jag arbetar med webbutveckling. Det hjälper mig att förstå hur HTML och CSS påverkar det som faktiskt visas i webbläsaren.
